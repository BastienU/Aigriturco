# Images du site

Dépose ici les images utilisées par le site, puis déclare-les dans `js/photos.js`.

Conseils :
- formats : `.jpg`, `.png` ou `.webp` ;
- poids : idéalement moins de 500 Ko par image (compression possible avec https://squoosh.app) ;
- noms : en minuscules, sans espace ni accent (ex : `soiree-amis.jpg`). En local sous Windows `Plage.JPG` et `plage.jpg` sont le même fichier, mais pas sur Vercel.
